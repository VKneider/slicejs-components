ProgressBar

Overview

ProgressBar shows how much work is complete when a total is known. Give it a meaningful label, a value and a max. For an operation whose total is temporarily unknown, use indeterminate.

When to use it

Uploads, batch jobs, storage quotas, or completion of a task with a measurable total. It displays progress; it does not upload files, schedule jobs, or own a wizard.

When not to use it

Use Loading for a general busy indicator, SkeletonService for content whose shape is known, and Stepper for the named stages of a process. A progress bar is not a chart or a circular gauge.

Behavior

  • Values are finite numbers clamped to 0…max. A nonpositive/nonfinite maximum falls back to 100. The assigned amount is retained, so increasing max can reveal an amount that was previously clamped.
  • label names the bar. An omitted label falls back to translated “Progress”; use a specific label in real apps. showLabel: false hides it visually while the bar retains its accessible name.
  • showValue exposes the formatted value beside the track. The default is a localized percentage; format(value, max) customizes both that value and aria-valuetext. ariaValueText overrides the spoken value without changing the visible one. Explicit locale wins over the app locale.
  • tone is semantic; size (sm, md, lg) controls track height. Props update without rebuilding.
  • indeterminate omits aria-valuenow/aria-valuetext: it never claims a fake percentage. With reduced motion it stays still; otherwise its fill moves. Returning to determinate restores the value.
  • The bar has role="progressbar" and min/max/current values. It is not a live region by default; announce meaningful milestones separately rather than every percentage tick.

Texts and theming

slice.progressBar.label and .working have English/Spanish defaults. The app dictionary wins; texts: { label, working } wins over the dictionary. Visible fallback texts follow locale changes. Colors follow theme tokens. Local CSS overrides: --slice-progress-bar-track, --slice-progress-bar-fill, --slice-progress-bar-radius, --slice-progress-bar-height and --slice-progress-bar-color.
